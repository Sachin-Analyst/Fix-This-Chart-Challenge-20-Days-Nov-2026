# Day 1 Color Palettes

Hex codes used in the Day 1 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background |
| Light blue | `#C3DFFE` | Question boxes |
| Yellow | `#FFDE59` | Day pill, creator pill and bonus box |
| Orange | `#FF751F` | Number circles |

---

## Chart Colors

Set in Power BI, for the chart columns.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Blue | `#118DFF` | Problem chart, all columns |
| Accent blue | `#3F7FF3` | Solution chart, FY25 column |
| Light grey | `#DDDFE7` | Solution chart, FY23 and FY24 columns |
