# Day 2 Color Palettes

Hex codes used in the Day 2 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages. Same template as Day 1.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background (Problem and Solution pages) |
| Light blue | `#C3DFFE` | Question boxes, solution point boxes, Rule #2 page background |
| Yellow | `#FFDE59` | Day pill, creator pill and bonus box |
| Orange | `#FF751F` | Number circles and dashed annotation boxes |

---

## Problem Chart Colors

Set in Power BI, pie chart "Sales by Category". No custom colors were set: Power BI assigned the default theme palette (Fluent2) to the 8 categories in alphabetical order.

| Category | Color | Hex Code |
| --- | --- | --- |
| Business Laptop | Blue | `#118DFF` |
| Desktop | Dark blue | `#12239E` |
| Gaming Laptop | Orange | `#E66C37` |
| Graphic Card | Purple | `#6B007B` |
| Keyboard | Pink | `#E044A7` |
| Mouse | Light purple | `#744EC2` |
| Personal Laptop | Gold | `#D9B300` |
| Processors | Red | `#D64550` |

---

## Solution Chart Colors

Set in Power BI, sorted bar chart "Revenue by Product Category". Focus approach: the top two categories get the accent, the other six are muted.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Accent blue | `#3F7FF3` | Personal Laptop and Business Laptop bars (top two), "● REVENUE" word in the chart header |
| Light grey | `#DDDFE7` | Desktop, Gaming Laptop, Graphic Card, Processors, Keyboard and Mouse bars |
| Black | `#000000` | "BY PRODUCT CATEGORY (₹ Millions)" in the chart header |
