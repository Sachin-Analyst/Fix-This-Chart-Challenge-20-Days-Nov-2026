## Project Description

This repository contains the daily body of work from the Codebasics "Fix This Chart" challenge.

Each day starts with one chart that looks fine at first glance. Every number in it is correct, and it still misleads. My task is to name three things I would change before the chart reaches the board, and to answer one bonus question.

Each day has three pages:

- *Problem:* the original chart, rebuilt in Power BI
- *Solution:* the fixed chart, with each fix numbered on the chart and in the boxes, plus the bonus answer
- *Rule:* one line to keep and check on every dashboard

Both charts use the same data. Only the chart settings change, so the fix comes from how the chart is shown, not from the numbers.

## Usage

### How Each Day Is Built

- The data is stored in a flat Excel table
- The charts are built in Power BI from that table
- The pages are designed in Canva and exported as a PDF

### What You Can Explore

- The original chart and what is wrong in it
- The three fixes, numbered on the chart
- The bonus answer with the calculation
- The data file and the Power BI file behind each chart

### Opening the Power BI File

Open the `.pbix` file in Power BI Desktop. The data was imported from the Excel file in the same folder. To refresh it on your own computer, update the file path under Transform data > Data source settings.
