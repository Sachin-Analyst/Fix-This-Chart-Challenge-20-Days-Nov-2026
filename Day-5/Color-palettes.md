# Day 5 Color Palettes

Hex codes used in the Day 5 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages. Same template as Day 1, Day 2, Day 3 and Day 4.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background (Problem and Solution pages) |
| Light blue | `#DCEEF8` | Question boxes, solution point boxes, Rule #5 page background |
| Yellow | `#FFDE59` | Day pill, creator pill and bonus box |
| Orange | `#FF751F` | Number circles and dashed annotation boxes |

---

## Problem Chart Colors

Set in Power BI, line chart "Sales by Region". No custom colors were set: Power BI used the default theme palette (Fluent2), so the line and its markers got the first theme color. The five regions (North, South, East, West, Central) are joined by one line, which makes the slope between two regions look like a trend.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Default blue | `#118DFF` | Line and the 5 markers (North, South, East, West, Central) |
| Dark grey | `#242424` | Chart title "Sales by Region" |
| Grey | `#616161` | Axis labels |

---

## Solution Chart Colors

Set in Power BI, sorted column chart "Sales by Region (₹ Million)". Focus approach: the top region gets the accent, the other four are muted. The columns are sorted high to low, with data labels and units.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Accent blue | `#3F7FF3` | South column (top region), "● SALES" word in the chart header |
| Light grey | `#DDDFE7` | West, North, East and Central columns |
| Dark grey | `#242424` | "BY REGION (₹ Million)" in the chart header, action title |
| Grey | `#616161` | Subtitle, data labels and axis labels |
