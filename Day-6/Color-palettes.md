# Day 6 Color Palettes

Hex codes used in the Day 6 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages. Same template as Day 1 to Day 5.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background (Problem, Solution and Bonus pages) |
| Light blue | `#DCEEF8` | Question boxes, solution point box, Rule #6 page background |
| Yellow | `#FFDE59` | Day pill and creator pill |
| Light yellow | `#FFEEAB` | Bonus box |
| Orange | `#FF751F` | Number circles and dashed annotation boxes (dashed boxes are set at reduced opacity) |

---

## Problem Chart Colors

Set in Power BI, two pie charts "Sales Share by Channel", one for FY24 and one for FY25. The three slice colors are the first three colors of the default theme palette (Fluent2), set for each channel so both pies match. Data labels and the built-in legend are turned off, and the legend is built from shapes and text boxes. Two pies force the eye to compare slices across separate circles.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Default blue | `#118DFF` | Retailer slices and legend swatch |
| Dark blue | `#12239E` | Direct slices and legend swatch |
| Orange | `#E66C37` | Distributor slices and legend swatch |
| Dark grey | `#242424` | Chart title "Sales Share by Channel", FY24 and FY25 headings, legend text |

---

## Solution Chart Colors

Set in Power BI, line chart "Sales Share %" with only FY24 and FY25 on the axis, one line per channel (a slopegraph). Focus approach: Direct gets the accent, the other two channels are muted. Both axes are hidden, markers are squares, and every point carries a data label.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Accent blue | `#3F7FF3` | Direct line and markers, "Direct" name label, "● SALES" word in the chart header |
| Grey | `#B3B3B3` | Retailer and Distributor lines and markers (theme white, darker 30%) |
| Dark grey | `#242424` | "SHARE BY CHANNEL (%)" in the chart header, action title, subtitle, channel names, FY24 and FY25 headings |
| Grey | `#616161` | Data labels |
