# Day 4 Color Palettes

Hex codes used in the Day 4 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages. Same template as Day 1, Day 2 and Day 3.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background (Problem and Solution pages) |
| Light blue | `#DCEEF8` | Question boxes, solution point boxes, Rule #4 page background |
| Yellow | `#FFDE59` | Day pill, creator pill and bonus box |
| Orange | `#FF751F` | Number circles and dashed annotation boxes |

---

## Problem Chart Colors

Set in Power BI, column chart "Units Sold by Product". No custom colors were set: Power BI used the default theme palette (Fluent2), so every product got the first theme color. The product names are rotated, and the long ones are cut off ("AQ Clx1 ...", "AQ Dracula HDD ...").

| Color | Hex Code | Used For |
| --- | --- | --- |
| Default blue | `#118DFF` | All 8 product bars (Clx1 Wireless Keyboard, Dracula HDD 3.5 inch, Elite Desktop Pro, Mforce Gen X Mouse, Pen Drive 2 in 1 64GB, Velocity SSD 1TB, Wi Power Dx3 Extender, Zion Saga 15 Laptop) |
| Dark grey | `#242424` | Chart title "Units Sold by Product" |
| Grey | `#616161` | Axis labels |

---

## Solution Chart Colors

Set in Power BI, sorted bar chart "Units Sold by Product (Thousands)". Focus approach: the top seller gets the accent, the other seven are muted. The bars are flipped to horizontal, so every product name sits on one line.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Accent blue | `#3F7FF3` | AQ Zion Saga 15 Laptop bar (top seller), "● UNITS" word in the chart header |
| Light grey | `#DDDFE7` | Velocity SSD 1TB, Mforce Gen X Mouse, Dracula HDD 3.5 inch, Pen Drive 2 in 1 64GB, Clx1 Wireless Keyboard, Wi Power Dx3 Extender and Elite Desktop Pro bars |
| Dark grey | `#242424` | "SOLD BY PRODUCT (Thousands)" in the chart header, action title |
| Grey | `#616161` | Subtitle, data labels and axis labels |
