# Day 3 Color Palettes

Hex codes used in the Day 3 pages and charts of the Fix This Chart challenge.

---

## Document Colors

Set in Canva, for the pages. Same template as Day 1 and Day 2.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Cream | `#FCF8E8` | Page background (Problem and Solution pages) |
| Light blue | `#DCEEF8` | Question boxes, solution point boxes, Rule #3 page background |
| Yellow | `#FFDE59` | Day pill, creator pill and bonus box |
| Orange | `#FF751F` | Number circles and dashed annotation boxes |

---

## Problem Chart Colors

Set in Power BI, column chart "Sales by city". No custom colors were set: Power BI used the default theme palette (Fluent2), so every city got the first theme color. The cities are in alphabetical order.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Default blue | `#118DFF` | All 8 city bars (Bengaluru, Chennai, Delhi, Hyderabad, Jaipur, Kolkata, Mumbai, Pune) |
| Dark grey | `#242424` | Chart title "Sales by city" |
| Grey | `#616161` | Axis labels |

---

## Solution Chart Colors

Set in Power BI, sorted column chart "Sales Performance by City". Focus approach: the top three cities get the accent, the other five are muted.

| Color | Hex Code | Used For |
| --- | --- | --- |
| Accent blue | `#3F7FF3` | Mumbai, Delhi and Bengaluru bars (top 3), "● SALES" word in the chart header |
| Light grey | `#DDDFE7` | Hyderabad, Chennai, Pune, Kolkata and Jaipur bars |
| Dark grey | `#242424` | "PERFORMANCE BY CITY (₹ Crores)" in the chart header, action title |
| Grey | `#616161` | Subtitle, data labels and axis labels |
